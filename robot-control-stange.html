Die Hand greift – durch den Roboter hindurch

Die Besucherin schiebt die Hand in die Schale am Ende der Stange. Der Roboter steht ihr gegenüber und schaut zu ihr: Was die Hand macht, macht der Greifer in dieselbe Richtung.

Handschale ziehenDie Stange dreht, kippt und schiebt sich. Senkt die Hand sich, fährt der Greifer zum Tisch; zieht sie zu sich, kommt er auf sie zu.
Space halten = Finger zusammendrückenDaumen und Zeigefinger stecken in Schlaufen. Ein Sensor misst den Abstand: zusammendrücken schließt den Greifer, locker lassen öffnet ihn.

Übertragung HAND → GREIFER

10 cm Handweg = 10 cm Greiferweg. Wie groß die Bewegungen sind, legt die Software fest: Die Stange kann kleiner oder größer sein als der Arbeitsbereich, solange die Richtung stimmt.

Gelenke des Roboters

Servo-Grenzen laut Achsendokument. Die Gelenke 1–4 sucht die Software selbst (inverse Kinematik), Gelenk 5 folgt dem Drehring, Gelenk 6 den Fingern. Handgelenk-Neigung höchstens 18°/s in der Simulation.

USB · Roboter und Bedienteil

Roboter – wie in der 3D-Steuerung: Chrome oder Edge, 115200 Baud. Nach dem Verbinden startet das Board neu (ca. 2 s), dann wird die Roboterposition gelesen. Erst danach folgt der Arm der Hand. Beim Übernehmen wird der Nullpunkt gesetzt, damit der Arm nicht springt. Fingerabstand und Drehring wirken absolut: Greifer und Werkzeug-Rotation fahren danach auf die Stellung der Hand. Meldet der Roboter Überlast, brummt es ebenfalls.

Bedienteil – 115200 Baud. Das Bedienteil schickt etwa 50-mal pro Sekunde eine Zeile H drehen kippen schieben finger ring: Drehen −35…35°, Kippen −5…65° (positiv = Hand tiefer), Schieben 260…560 mm (Drehpunkt bis Handschale), Fingerabstand 0…60 mm, Drehring −90…90° (optional). Beispiel: H -12.5 30 410 22 15. Die Seite antwortet mit V 0…255 für die Vibrationsmotoren. Solange das Bedienteil verbunden ist, sind Maus und Tastatur für die Hand gesperrt.

Arduino-Beispiel für das Bedienteil
// Potis an A0–A4, Vibrationsmotoren über Transistor an Pin 5 und 6.
// Werte mit euren Sensoren kalibrieren (min/max).
void setup() {
  Serial.begin(115200);
  Serial.setTimeout(5);
  pinMode(5, OUTPUT); pinMode(6, OUTPUT);
}
float lin(int pin, float a, float b) {
  return a + (b - a) * analogRead(pin) / 1023.0;
}
void loop() {
  Serial.print("H ");
  Serial.print(lin(A0, -35, 35));  Serial.print(' '); // Drehen
  Serial.print(lin(A1, -5, 65));   Serial.print(' '); // Kippen
  Serial.print(lin(A2, 260, 560)); Serial.print(' '); // Schieben
  Serial.print(lin(A3, 0, 60));    Serial.print(' '); // Finger
  Serial.println(lin(A4, -90, 90));                   // Drehring
  while (Serial.available()) {
    if (Serial.read() == 'V') {
      int v = Serial.parseInt();
      analogWrite(5, v); analogWrite(6, v);
    }
  }
  delay(20);
}
